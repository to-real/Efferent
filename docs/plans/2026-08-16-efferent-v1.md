# Efferent v1 实施计划（三旗舰：品牌件 · 任务中心 · 自动化）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 SPEC-0001 的 v1：品牌身份件（引擎字样对用户不可见）+ 任务中心 + 自动化管理，底盘复用不动。

**Architecture:** 品牌件全部在 Electron 层（图标/窗口标题/关于面板/启动页，与引擎插槽无关）；任务中心与自动化是**产品自有窗口**（本地页面），经引擎 HTTP/WS API 读取数据——不嵌入引擎 UI，规避插件持久化难题。AppService 组合根扩展 splash 与 taskCenter 依赖，保持接缝 1 可测性。

**Tech Stack:** 继承（Electron 43 / TS / vitest / Playwright / electron-builder）。新增：图标生成用引擎自带 sharp（resources/engine 依赖，脚本调用）。

**质量基线（对齐结论）**：简历级成熟度——每任务 TDD、PR 流程、文档随行。
