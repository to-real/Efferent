# ZCode 工作台功能面调研（第一手体验枚举）

> 方法论说明：本清单来自对该产品界面的直接使用体验（2026-08-16 全天深度会话），每条标注会话内证据。与网络调研的 ChatGPT/Claude/Codex 清单（另两份文档）合成竞品矩阵。

## 1. 会话与任务管理
- 多会话侧栏：会话列表、标题自动生成、当前会话高亮
- 会话恢复与上下文延续：长会话自动摘要延续到下一上下文窗口（本会话多次发生）
- 跨会话记忆：持久化记忆文件 + 每会话自动加载索引（MEMORY.md 机制）

## 2. 计划与进度（本会话最显性的工作台特征）
- **计划模式**：探索→出计划→用户审批→执行（今天 grilling/计划阶段反复使用）
- **实时任务清单**：执行期的 Todo 看板，随进度实时更新（用户全程可见 10 任务滚动到全绿）
- 任务清单与会话绑定，跨轮次持续

## 3. 工具调用透明化
- 每次工具调用一张卡：工具名、输入参数、输出结果，可展开折叠
- 命令执行卡（含退出码）、文件读写卡、网络搜索卡（带来源列表）
- 工具卡在流中即时出现（执行前可见意图）

## 4. 权限与安全
- 工具在用户选定的权限模式下运行；敏感操作有确认流
- 安全护栏显式成文（如 git 保护规则、删除前确认原则）
- 浏览器操作在用户可见窗格中进行（非黑箱）

## 5. 浏览器自动化（右侧窗格）
- 内置浏览器面板：导航、DOM 快照、截图、坐标交互
- 用户全程可见自动化过程，可随时人工介入

## 6. 自动化与后台任务
- 定时任务系统：创建/列出/更新/删除（cron 与自然语言时间表）
- 后台任务：后台 shell/代理 + 完成通知 + 输出检索
- 子代理并行：多代理同时执行独立任务，互不干扰

## 7. 输入与附件
- 图片粘贴/拖入（会话中用户多次贴截图）
- 斜杠命令/技能系统（大量可调用技能）
- 多行输入、会话中途追问

## 8. 模型与配置
- 模型选择、思考层级
- MCP 工具接入（如 JS REPL）
- 环境/工作目录概念显式

## 9. 值得注意的「非功能面」
- 流式输出的节奏感（用户等待体验）
- 中断与继续：任务通知不打断主流程
- 错误呈现：失败堆栈直接可见，不隐藏

## 桌面端独占性判断（待与另两份调研对照）
内置浏览器窗格、本地文件系统深度操作、本地进程管理（后台任务/子代理）、跨会话本地记忆——这些天然绑定桌面/本地形态。
